# Ανάλυση Χαρτοφυλακίου Μετοχών (R & Python)

Μάθημα: **Χρηματοοικονομικά Υπολογιστικά Πακέτα**. Ανάλυση χαρτοφυλακίου 4 μετοχών (AMD, AXON, GME, PFE) με χρήση ημερήσιων και μηνιαίων ιστορικών δεδομένων τιμών (2010-2013).

## Τι περιέχει

- **`assignment_brief.md`** — η εκφώνηση της εργασίας.
- **`portfolio_analysis.R`** — πλήρης λύση σε R (base, xts, zoo, quantmod).
- **`portfolio_analysis.py`** — ισοδύναμη λύση σε Python (pandas, numpy), ίδια λογική/τύποι, για επαλήθευση/cross-check.
- **`Portfolio_Analysis_Report.docx`** — αναλυτικό κείμενο με όλα τα αποτελέσματα, πίνακες και ερμηνείες.
- **`data/`** — ιστορικά δεδομένα τιμών (csv) για όλες τις μετοχές των 3 ομάδων (βλ. πίνακα παρακάτω), συν μερικά δεδομένα-παραδείγματα του μαθήματος (AMZN, IBM, SPY, SLY, TSLA).

## Ομάδες μετοχών ανά επίθετο

Η εκφώνηση ορίζει 3 διαφορετικές 4άδες μετοχών, ανάλογα με το αρχικό γράμμα του επιθέτου:

| Επίθετο | Μετοχές (με τη σειρά επένδυσης) | Αρχικό κεφάλαιο |
|---|---|---|
| Α έως Ι | AMD, AXON, GME, PFE | 4.000 / 3.000 / 2.000 / 2.000 |
| Κ έως Μ | AAPL, AAL, F, NVDA | 4.000 / 3.000 / 2.000 / 2.000 |
| Ν έως Ω | DIS, GME2, MSFT, PFE2 | 4.000 / 3.000 / 2.000 / 2.000 |

Τα scripts σε αυτό το repo (`portfolio_analysis.R` / `.py`) είναι γραμμένα για την ομάδα **Α έως Ι (AMD, AXON, GME, PFE)**. Για να τα προσαρμόσεις σε άλλη ομάδα, αλλάζεις μόνο:
1. τα 4 tickers (σε όλα τα σημεία `import_stock(...)` / `load(...)`),
2. τα ποσά επένδυσης (`i.AMD`, `i.AXON`, ... στο R / `INVESTMENT = {...}` στο Python) σύμφωνα με τον παραπάνω πίνακα,
3. προαιρετικά, τις ημερομηνίες περιόδων αν τα δεδομένα της άλλης ομάδας καλύπτουν διαφορετικό εύρος ημερομηνιών από 31/12/2010-30/12/2013 (έλεγξε πρώτα με `dim()`/`head()`/`tail()`).

Η υπόλοιπη λογική (SMA, RSI, κίνδυνος χαρτοφυλακίου, βελτιστοποίηση Markowitz) παραμένει ίδια ανεξαρτήτως ομάδας.

## Τι καλύπτει η ανάλυση

1. **Έλεγχος δεδομένων** — οπτικός έλεγχος, έλεγχος διάστασης, συνοπτικά στατιστικά.
2. **Συνολικές αποδόσεις** τίτλων σε δεδομένη περίοδο επένδυσης (adjusted close vs. price return).
3. **Δείκτης SMA Crossover** (50/200 ημερών) — σήματα αγοράς/πώλησης.
4. **Δείκτης RSI** (14 ημερών, μέθοδος Wilder) — σήματα υπεραγοράς/υπερπώλησης.
5. **Απόδοση & κίνδυνος χαρτοφυλακίου** για δεδομένα βάρη επένδυσης (variance-covariance matrix).
6. **Βελτιστοποίηση χαρτοφυλακίου (Markowitz)** — εύρεση Χαρτοφυλακίου Ελάχιστου Κινδύνου και Χαρτοφυλακίου Μέγιστου Δείκτη Sharpe, με πλέγμα βαρών 1% πάνω σε μηνιαία δεδομένα.

## Πώς τρέχει

**R:** άνοιξε το `portfolio_analysis.R` σε RStudio (ή Posit Cloud), εγκατέστησε `xts`, `zoo`, `quantmod` (`install.packages(c("xts","zoo","quantmod"))`), βεβαιώσου ότι το working directory είναι η ρίζα αυτού του project, και τρέξε με **Source with Echo**.

**Python:** `pip install pandas numpy` και μετά `python portfolio_analysis.py` από τη ρίζα του project.
